# 🖥️ معهدّي — تطبيق سطح المكتب (Flutter Desktop-First)

النموذج الأولي القابل للتشغيل لنظام إدارة المعاهد الذكي — **Windows أولًا** بنفس الواجهات العصرية المطلوبة في الوثيقة.

> **الإصدار الحالي: v3.6**
> الجديد في هذه النسخة: **اعتماد الحلول المالية الست كاملة**
> - الاستحقاق بالجلسة المنفذة لا بمجرد التسجيل
> - دفتر ثلاثي لكل دورة: تعاقدي / محقق / مصروف
> - سقف نسبة المعلم ≤ 50% مع سجل تدقيق
> - تنبيه عند تجاوز هامش المعهد 70%
> - فصل المستحق عن المصروف
> - قفل الدورة المالية عند الإغلاق

## التشغيل أول مرة
```bash
cd flutter_app
flutter pub get
flutter create --platforms=windows .
flutter run -d windows
```

## التشغيل عند استبدال نسخة سابقة
```bash
cd E:\projects\Smart-Private-Educational-Institute-Program
flutter run -d windows
```
> لا توجد حزم جديدة في هذا الإصدار، لذلك إن كانت الاعتماديات موجودة سابقًا فلا حاجة لأي تنزيل إضافي.

## ما يعرضه النموذج الآن (بيانات تجريبية)
| الشاشة | ما تغطيه |
|--------|----------|
| **لوحة القيادة** | مؤشرات فورية + تنبيهات + توزيع المواد والإيرادات |
| **الطلاب** | سجل الطالب + المواد المسجل بها + حالة مالية |
| **التسجيل والانتظار** | طلبات التسجيل + قوائم الانتظار + اقتراح البديل |
| **الدورات والمجموعات** | إنشاء دورة + اعتماد المدير العام + نسبة المعلم + ملخص مالي |
| **المدرسون** | بيانات المدرس الكاملة + تقييم الإدارة + معتمد/مصروف/قيد الصرف |
| **الفواتير والأقساط** | الفواتير + المتبقي + الحسومات المرنة |
| **المحاسبة** | دفتر ثلاثي + إشعارات التعويض + سجل تدقيق + ربحية المواد |
| **التقارير** | تقرير جلسة وتقرير كورس وفق الاستحقاق المنفذ |

## الخطوة التالية بعد نجاح التشغيل
1. **ربط قاعدة البيانات المحلية SQLite/Drift** بمخطط `database/schema_sqlite.sql`.
2. جعل شاشة **طلب التسجيل** تحفظ فعليًا بدل الاعتماد على Mock Data.
3. الانتقال بعدها إلى الطباعة PDF والنسخ الاحتياطي المحلي.
