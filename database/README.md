# 🗄️ الحزمة التقنية — قاعدة بيانات نظام إدارة المعاهد الذكي

## محتويات المجلد
| الملف | الوصف |
|-------|-------|
| **schema.sql** | المخطط الكامل لـ PostgreSQL 14+: 16 قسمًا، 40+ كائنًا (جداول + أنواع ENUM + Views محاسبية جاهزة) — للخادم السحابي عند التوسع SaaS |
| **schema_sqlite.sql** | نسخة SQLite مطابقة (45 جدولًا + 6 Views) — **لتطبيق سطح المكتب Offline-First** مع Drift في Flutter |
| **ERD.svg** | مخطط علاقات الكيانات البصري (8 لوحات × 30 كيانًا + التدفق الذهبي) |
| **gen_erd.py** | سكربت توليد المخطط (لإعادة التوليد بعد أي تعديل) |

## خريطة schema.sql
| القسم | المحتوى |
|-------|---------|
| 0 | 16 نوع ENUM (حالات، فترات صباحي/مسائي، نطاقات الحسم...) |
| 1 | النواة: institutes (Multi-Tenant) + branches + rooms |
| 2 | المستخدمون + RBAC + audit_logs |
| 3 | الهيكل الأكاديمي: subjects, levels, terms |
| 4 | الطلاب + أولياء الأمور (M:N) |
| 5 | المدرسون + السعة + التوفر الزمني |
| 6 | الموظفون + الحضور + الإجازات |
| 7 | **course_templates → groups → sessions** + bookings (الخصوصي) |
| 8 | **registration_requests + waiting_lists + enrollments** ⭐ قلب نظام الاختيار الحر |
| 9 | الحضور لكل مجموعة |
| 10 | الاختبارات + الدرجات + الشهادات برقم تحقق |
| 11 | الفواتير + الأقساط + المدفوعات + **discounts (الحسم المرن)** |
| 12 | مستخلصات المعلمين + رواتب الموظفين + **الصرفيات** |
| 13 | المخزون المرتبط بحسابات المواد |
| 14 | الإشعارات متعددة القنوات |
| 15 | ai_predictions (الإنذار المبكر) |
| 16 | **6 Views محاسبية جاهزة**: حساب المادة/الطالب/المعلم + تقرير الجلسة + لوحة الدورات + نقص المخزون |

## التشغيل
```bash
createdb sims_db
psql -d sims_db -f schema.sql
```

## قرارات تصميمية أساسية
1. **`institute_id` في كل جدول تشغيلي** → عزل كامل لبيانات كل معهد مشترك (SaaS).
2. **الثمن النهائي يُخزَّن في `enrollments.agreed_price`** لحظة التسجيل → تقارير تاريخية صحيحة حتى لو تغيرت الأسعار أو انتهت مدة الحسم.
3. **`sessions.teacher_cost`** تُخزَّن لكل جلسة → حساب استحقاق المدرس تلقائيًا ودقيقًا (يدعم الإحلال).
4. **UNIQUE (student_id, group_id)** يمنع التسجيل المزدوج، و**UNIQUE (session_id, student_id)** يمنع تكرار الحضور.
5. **قائمة الانتظار** بفهرس فريد (طالب×مدرس×مادة×فترة) + `priority` + `expires_at` لمهلة قبول المقعد.
