# 🖥️ معهدّي — تطبيق سطح المكتب (Flutter Desktop-First)

النموذج الأولي القابل للتشغيل لنظام إدارة المعاهد الذكي — **Windows أولًا** بنفس الواجهات العصرية المطلوبة في الوثيقة (القسم 9).

## التشغيل أول مرة
```bash
cd flutter_app
flutter pub get
flutter create --platforms=windows .   # توليد مجلد windows/ للتشغيل على سطح المكتب
flutter run -d windows
```
> لاحقًا عند التوسع للمنصات الأخرى (كما اتفقنا — في وقت لاحق):
> `flutter create --platforms=android,ios,web .`

## ما يعرضه النموذج الآن (بيانات تجريبية)
| الشاشة | المتطلب الذي يغطيه (وثيقة المواصفات §9) |
|--------|------------------------------------------|
| **لوحة الدورات** | بطاقة لكل مجموعة: عدد المسجلين/السعة، المقاعد المتاحة، الفترة (صباحي/مسائي)، عدد قائمة الانتظار |
| **لوحة المدرسين** | عدد المسجلين لكل معلم + نسبة إشغال مجموعاته + قوائم انتظاره |
| **شاشة الطالب** | ملف الطالب + المواد المسجَّل بها (المدرس، الفترة، الجدول، الحضور، الحالة المالية) |
| مؤشرات عليا | إجمالي الطلاب، الإيرادات، طلبات معلقة، قوائم انتظار |

```
    ├── teachers_dashboard.dart# لوحة المدرسين

```
